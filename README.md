A one-line resignation letter written in the voice of a cron job that has fired every minute since March — entered on make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 in USDC, top 3 paid).

## Run it

```sh
node main.ts
```

The program writes the single resignation line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt` when run locally).
